# Проект банковского приложения
## Описание:
Проект банковского приложение для анализа транзакций,
которые находятся в Excel-файле. Приложение генерирует
JSON-данные для веб-страниц, формирует Excel-отчеты,
а также предоставляет другие сервисы.
## Установка
1. Клонируйте репозиторий
`git clone https://github.com/stepanbaidakov/course_work_1.git`
2. Установите зависимости:
`pip install -r requirements.txt`
## Использование
1. Откройте файл `main.py`
2. Запустите функцию `main()`
